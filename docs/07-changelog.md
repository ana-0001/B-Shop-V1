## [1.3.0] — 2026-11-07

### إضافة — شريط الحالة في كل الشاشات + فحص متطلبات حقيقي للإقلاع مع مسار فشل مؤتمت
تنفيذ طلبَي صاحب المشروع: **(1)** إظهار شريط الحالة النظامي في الشاشة الافتتاحية وتسجيل الدخول وشاشات الأخطاء والرئيسية، و **(2)** الشاشة الافتتاحية تفحص المتطلبات فحصًا فعليًا — النجاح: انتقال تلقائي، والفشل: شاشة الأخطاء مع إعادة محاولة أوتوماتيكية بفواصل + زر يدوي.

#### 1) شريط الحالة في كل الشاشات
- `layouts/auth.vue` — استبدال تذييل حالة الزائر القديم (`splash.guestStatus` + `splash.dbMode`) بـ `<SystemStatusBar />` — فيغطي **الإقلاع + تسجيل الدخول + الشروط + الإعداد**. حُذفت المفتاحان اليتيمان من الكتالوجين (282 مفتاحًا متوازنًا).
- `app/error.vue` — الشريط في أسفل كل حالات الأخطاء (404/500/503) بدل التذييل التشخيصي القديم؛ رقم الكود والتفصيل ظاهران داخل بطاقة الخطأ نفسها.
- الشاشة الرئيسية وبقية مساحة العمل كانت مغطاة بالفعل عبر `layouts/default.vue`. رقاقة المستخدم تختفي تلقائيًا قبل تسجيل الدخول (`v-if="auth.user"`) ومركز الإشعارات يفشل بهدوء قبل تحميل البيانات.

#### 2) فحص المتطلبات الحقيقي (useBootChecks) بدل التسلسل المحاكى
- `components/splash/useBootChecks.ts` — كومبوزابل جديد ينفّذ المتطلبات الخمسة **فحصًا فعليًا** بالترتيب: وحدات النظام (localStorage/Intl/crypto/JSON) → قاعدة البيانات المالية (نداء `systemApi.meta()` والتحقق من الفروع والكتالوج ونسبة الضريبة) → اللغة والسمة (الكتالوجات + قيم locale/theme + سمات html) → محرك الرسوميات (رسم Canvas 2D وقراءة بكسل وتوليد DataURL للطباعة الحرارية) → الجاهزية (تجميع النتائج + حلّ مسارات التوجيه). لكل خطوة حد أدنى للعرض 380ms.
- `pages/index.vue` — النجاح: توجيه تلقائي للوجهة التالية بعد 450ms (دخول/شروط/إعداد/رئيسية حسب الجلسة). الفشل: مهلة 900ms لإظهار الخطوة الفاشلة ثم `showError` بكود **503** مع `data: { bootFailed, failedKey, detail }`. حماية من التشغيل المتزامن لزر إعادة الفحص.
- `BootStepsList.vue` — حالات حقيقية لكل خطوة: انتظار/جارية (دوران)/نجاح ✓ OK/فشل ✗ FAIL بأحمر `text-err`.

#### 3) شاشة الأخطاء الجديدة 503 (فشل فحص المتطلبات)
- `ErrorState.vue` — توسيع نوع الكود ليشمل `'503'` (ترويسة تحذير حمراء + مفاتيح `err503.*`).
- `app/error.vue` — عند `data.bootFailed`: عرض **الفحص الذي فشل** بالتسمية المترجمة + **التفصيل الفني** بخط mono + **عدّاد إعادة محاولة أوتوماتيكية** (10 ثوانٍ مع شريط تقدم وأسطر `aria-live="polite"`) يرجع تلقائيًا لشاشة الإقلاع لإعادة الفحص، + زر **«إعادة المحاولة الآن»** وزر **«تحديث التطبيق»** (تحميل كامل من الخادم). سلوك 404/500 الأصلي دون تغيير.
- مفاتيح i18n جديدة: `err503.code/title/desc` و `errBoot.failedCheck/detail/autoRetry/retryNow/refresh` (بالإنجليزية والعربية).
- رفع `appVersion` إلى `1.3.0`.

## [1.2.0] — 2026-11-06

### إضافة — دمج محتويات الفوتر القديم جوه شريط الحالة + توحيد هوية الألوان مع خطة الشريط
تنفيذ القرارين المتبقيين من صاحب المشروع: **(1)** شريط الحالة يستبدل الفوتر *مع نقل محتوياته الحالية جوه الشريط الجديد*، و **(2)** استبدال ألوان المشروع كلها بألوان خطة شريط الحالة (PRD).

#### 1) نقل محتويات الفوتر القديم جوه الشريط النظامي
الفوتر القديم (`shared/StatusBar.vue`) كان فيه: حالة الاتصال + المستخدم + التبويبات المفتوحة + الساعة + نسخة الفِسقال. الحالة والساعة كانوا مغطّيين بالفعل بالـ PRD، والباقي اتنقل كوحدات ذرّية جديدة في `elements/`:
- `SsbUserChip.vue` — رقاقة المستخدم الحالي: أيقونة + الاسم المعروض + شارة "منشئ النظام" الذهبية المصغّرة لو الحساب هو bomba (نفس منطق الفوتر القديم حرفيًا من `useAuthStore`).
- `SsbTabsChip.vue` — رقاقة التبويبات المفتوحة: أيقونة + التسمية + العدّاد بخط mono وأرقام جدولية (تفاعلي مع `useInvoicesStore().tabs` لحظيًا).
- وسم نسخة الفِسقال (`splash.fiscalBuild`) رجع جنب الساعة في منطقة النهاية زي مكانه في الفوتر القديم — بخط mono خافت و`unicode-bidi: plaintext` عشان السلسلة المختلطة (EGP + ج.م) ما تتجمدش في العربي.
- التوزيع النهائي: **Start** = نبضة الصحة + شارة الإصدار + وسم البيئة | فاصل | المستخدم + التبويبات — **End** = الساعة | فاصل | نسخة الفِسقال | فاصل | الإشعارات + الإعدادات.
- إخفاء تدريجي جديد: ≤64em يخفي الفِسقال، ≤48em يخفي التبويبات، ≤30em يخفي رقاقة المستخدم.
- مفاتيح i18n جديدة: `ssb.user.aria` و `ssb.tabs` (بالإنجليزية والعربية — 276 مفتاحًا متوازنًا).

#### 2) استبدال هوية الألوان للمشروع كله بألوان خطة الشريط (PRD Literal)
توكنز `main.css` (Light + Dark) اتظبطت كلها على لوحة الـ PRD — كل صبغات المشروع دلوقتي من عائلات الخطة بس: **45 ذهبي / 220 كحلي / 30 دافي / 142 أخضر / 0 أحمر**:

- مرساة قياس واحدة `--ssb-em` على `.ssb` وعلى الحاويات المنقولة عبر Portal (`ssb-pop-content`/`ssb-drawer-content` لأنها خارج شجرة `.ssb`) — تغيير قيمتها الواحدة يقيّس الشريط كله (ارتفاع/مسافات/خطوط/حدود/ظلال) بنسب ثابتة.

- استبدال أدوات Tailwind المعتمدة على rem داخل المناطق (`gap-1`, `w-px h-3`, `mx-0.5`…) بأصناف CSS نسبية: `.ssb-zone` / `.ssb-zone-start` / `.ssb-zone-end` / `.ssb-separator` — كلها em.
- ضبط مسافات الدرج: `gap-2`/`mt-2`/`w-3.5` → `gap-[0.5em]`/`mt-[0.5em]`/`w-[0.875em]`.

## [1.1.0] — 2026-11-06

تنفيذ كامل لوثيقة `07-1-PRD-StatusBar.md` بنسخة Vue 3 المكافئة لبيئة المشروع الحالية (قرار صاحب القرار: "التنفيذ بما يتناسب مع بيئة العمل الحالية والمكاتب الحالية")، مع اعتماد **ألوان الـ PRD حرفيًا** (ذهبي `hsl(45 85% 62%)`، خلفية فاتحة `hsl(30 20% 98%)`، غامقة `hsl(220 15% 12%)`) والساعة بصيغة **12 ساعة + Tooltip احترافي** حسب اختيارات صاحب المشروع.

#### وحدة جديدة `app/components/system-status-bar/` (بنيّة PRD الثلاثية)
- `SystemStatusBar.vue` — نقطة الدخول: ثلاث مناطق بخصائص CSS منطقية (Start/Center/End) لانعكاس RTL/LTR سلس + حركة دخول نابضة (spring cubic-bezier).
- `zones/` — `SsbStartZone` (نبضة الصحة + شارة الإصدار الذهبية + وسم البيئة) · `SsbCenterZone` (الشعار الرسمي + الاسم + السطر التعريفي) · `SsbEndZone` (الساعة + الثيم + اللغة + الإشعارات + الإعدادات + أزرار النافذة Tauri).
- `elements/` — `SsbPulseDot` (aria-live="polite") · `SsbVersionBadge` · `SsbEnvTag` (DEV/PROD) · `SsbBrandMark` · `SsbLiveClock` (Popover التحويم) · `SsbNotificationBell` · `SsbThemeToggle` · `SsbLanguageToggle` · `SsbSettingsTrigger`.
- `composables/` — `useLiveClock` (12h + 24h بتوقيت `Africa/Cairo` + ميلادي + هجري **أم القرى** `islamic-umalqura` بصيغة PRD `Tuesday : 25 - (11 - Dhu al-Qi'dah) - 1447 AH` مع كاش منسّقات Intl) · `useSystemStatus` (online/degraded/offline مشتقة من دورة المزامنة) · `useNotificationCenter` (إشعارات Mock مشتقة: فواتير معلّقة من الـ API + مخزون منخفض من الـ inventory + أحداث sync/db-reset من ناقل الأحداث، مع تعليم كمقروء وحذف وتفريغ وسقف 30 إشعارًا).
- `SettingsDrawer.vue` — درج جانبي (reka-ui Drawer) بمظهر النيومورفيزم: المظهر (Light/Dark/System) + اللغة + الفرع الحالي + المنطقة والتوقيت (القاهرة مثبتة مع ملاحظة الجاهزية لـ RegionSettings حسب خارطة الطريق) + بطاقة "عن النسخة".
- `status-bar.css` — توكنز `--ssb-*` معزولة تحت جذر `.ssb`: زجاج `backdrop-blur(12px)` + ظل مزدوج مرفوع + ظل داخلي للضغط + ارتفاع صارم `1.5em` + استجابة تدريجية (إخفاء العلامة/التاجليت حسب العرض) — بدون أي px.

- **اعتماديات بيئة التطوير**: تثبيت `@vue/devtools-api` (استيراد اختياري في vee-validate كان يكسر الـ Vite Dev Overlay).
