# 00 — نظرة عامة على مشروع B-Shop

> آخر تحديث: نوفمبر 2026 · الإصدار 1.0.0

## إيه هو B-Shop؟

**B-Shop** نظام إدارة محلات وشركات تجارية (ERP / POS) بيشتغل كتطبيق ويب وسطح مكتب في نفس الوقت. النظام بيبدأ بمحل واحد بس، ومبني من الأول بحيث يتوسع لاحقًا لعدة شركات وفروع **من غير إعادة كتابة** — عشان كده كل نموذج بيانات فيه `tenantId` و `companyId` و `branchId` من اليوم الأول.

## الوحدات الأساسية

| الوحدة | المسار | بتعمل إيه |
|---|---|---|
| شاشة الإقلاع | `/` | فحص ذاتي بخمس خطوات وتوجيه تلقائي حسب حالة الجلسة |
| تسجيل الدخول | `/auth/sign-in` | معرّف موحد (اسم مستخدم / بريد / موبايل مصري) مع كشف تلقائي للنوع |
| الشروط والأحكام | `/terms` | 5 بنود إلزامية + مربع موافقة بيفعّل زر القبول |
| الإعداد الأولي | `/onboarding` | معالج 4 خطوات: ترحيب → ملف شخصي → ثيم ولغة → إكمال |
| لوحة التحكم | `/dashboard` | بطاقات إحصائية + شارت أسبوعي (Chart.js) + دائرة توزيع + آخر الفواتير |
| الفواتير | `/invoices` | تبويبات متعددة، Split View، تعليق (Hold)، ترحيل، وطباعة (print-js) |
| الحسابات | `/accounts` | ملخص مالي (مبيعات/مشتريات/مرتجعات) + دفتر الفواتير |
| المخازن | `/inventory` | المخزون حسب الفرع بجدول TanStack Table قابل للفرز والبحث |
| التقارير | `/reports` | تقارير تحليلية حسب نوع الفاتورة بأشرطة توزيع |
| الأخطاء | `/[...slug]` + error.vue | شاشات 404 و 500 بنفس هوية النظام |

## تسجيل الدخول التجريبي

| الحقل | القيمة |
|---|---|
| اسم المستخدم | `bomba` |
| كلمة المرور | `bomba000` |
| بريد أساسي | `bomba000@bomba.com` |
| بريد ثانوي | `bomba001@bomba.com` |
| موبايل أساسي | `01281130712` |
| موبايل ثانوي | `01281130713` |

الحساب ده هو **صانع النظام** (المستوى 900) — ليه صلاحيات كاملة ALLOW_ALL (راجع `04-auth-and-seed.md`).

> ⚠️ كلمة المرور مخزنة نصًا في طبقة الـ Mock للتجربة فقط — التشفير bcrypt في الباك إند (راجع `06-backend-migration.md`).

## القرارات الافتراضية المعتمدة

1. كل الملفات والفولدرات بتنشأ فعليًا — مش وصف.
2. المنتجات التجريبية **عامة** (إلكترونيات، مواد غذائية، أدوات منزلية، مستلزمات مكتبية) بأسعار واقعية بالجنيه المصري.
3. اللغة الافتراضية English (en, LTR) والثانية العربية المصرية (ar, RTL).
4. الثيم الافتراضي Light ويدعم Dark و System.
5. ضريبة القيمة المضافة الافتراضية **14%**.

## سلسلة الأدوات

Nuxt 3 (Vue 3 + TypeScript) · Tailwind CSS · shadcn-vue (reka-ui) · TanStack Table · Lucide · Vue Sonner · Pinia + Persisted State · ofetch · VeeValidate + Zod · Chart.js · date-fns · print-js · nuxt-auth-utils · Tauri.

## الهيكل المختصر

```
b-shop/
├── app/                  ← كل كود الواجهة (srcDir)
│   ├── assets/css/       ← توكنز التصميم HSL + مكونات erp-*
│   ├── components/       ← ui/ + shared/ + auth/ + invoices/ + dashboard/ + onboarding/ + splash/
│   ├── composables/      ← useI18n / useAppData / useSystemMeta / useClock / useSonner
│   ├── layouts/          ← default (شل النظام) + auth (شل ما قبل الدخول)
│   ├── locales/          ← en.json + ar.json
│   ├── middleware/       ← auth.global.ts + super-bomba.ts
│   ├── pages/            ← 10 صفحات
│   ├── schemas/          ← مخططات Zod
│   ├── services/         ← api/ (ofetch) + mock/ (seed + db + handlers)
│   ├── stores/           ← Pinia: auth + invoices + preferences
│   └── types/ + utils/   ← العقود والأدوات المساعدة
├── docs/                 ← التوثيق (الملف اللي بتقرأه الآن)
├── public/               ← favicon + نسخة الـ logo
├── server/api/           ← فارغ — جاهز للباك إند
└── src-tauri/            ← غلاف سطح المكتب (Rust)
```
